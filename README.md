# Bangla Vibe Daily — website

Showcase site for the [Bangla Vibe Daily](https://www.youtube.com/@BanglaVibeDaily) YouTube channel
and [Facebook page](https://www.facebook.com/BanglaVibeDaily).

**Live:** https://banglavibedaily.github.io

The page introduces the channel, shows its seven content categories, and lists videos:
a **Featured** row you pick by hand and a **Latest videos** grid that refreshes itself daily
from the channel's public YouTube feed.

## Run it

### With Docker (recommended — Node 22, same as CI)

```bash
cp container/main/.env.example container/main/.env
cp container/main/.envs/app.env.example container/main/.envs/app.env

docker compose -f container/main/compose.yml up            # http://localhost:5173
docker compose -f container/main/compose.yml run --rm app npm test
docker compose -f container/main/compose.yml run --rm app npm run fetch:videos
docker compose -f container/main/compose.yml run --rm app npm run build
```

If Docker says *permission denied* on `/var/run/docker.sock`, add yourself to the docker group
once — `sudo usermod -aG docker $USER` — then log out and back in.

### Without Docker (Node 18.19+)

```bash
cd source/main
npm install
npm run dev          # http://localhost:5173
npm test             # run the test suite
npm run build        # production build → dist/
npm run preview      # preview the production build
```

## Editing the site

**All text lives in `source/main/src/data/content.js`.** Nothing else needs touching for
day-to-day changes.

### Feature a video

Add its link to `featured` — a watch URL, a `youtu.be` link, a Shorts link or a bare video id:

```js
export const featured = [
  'https://www.youtube.com/watch?v=XXXXXXXXXXX',
];
```

Titles are looked up automatically. An empty list hides the whole Featured section.

### Hide a video from "Latest videos"

`skip.titleKeywords` hides anything whose title contains one of the words (case-insensitive);
`skip.videoIds` hides specific videos:

```js
export const skip = {
  titleKeywords: ['infobells', 'movkidz', 'rhyme'],
  videoIds: ['https://youtu.be/XXXXXXXXXXX'],
};
```

`rhyme` is there to keep re-uploaded third-party nursery rhymes off the site. **Remove it once
the channel publishes its own rhyme videos**, or they will be hidden too.

### Never edit `src/data/videos.json`

It is regenerated by `npm run fetch:videos` on every deploy and any manual change is lost.

## How the daily refresh works

`scripts/fetch-videos.mjs`:

1. Reads `https://www.youtube.com/feeds/videos.xml?channel_id=UCECjH_U3T2l4SSXiVtBrajQ`
   (the channel's public feed — the latest 15 uploads, no API key needed).
   YouTube answers this endpoint with an occasional spurious 404, so the script retries 4 times.
2. Drops everything matching the skip list, sorts newest first, keeps 12.
3. Looks up each featured video's title via YouTube's public oEmbed endpoint.
4. Writes `src/data/videos.json`.

If the feed is unreachable, the script logs a warning, keeps the previous list and still exits 0,
so a YouTube outage can never break a deploy.

The GitHub Action runs this, then the tests, then the build, and publishes to Pages:

- on every push to `main`
- daily at 00:30 UTC (06:30 Bangladesh time)
- whenever you press **Run workflow**

> **Note:** GitHub pauses scheduled workflows in a repository with no activity for 60 days.
> It emails you first; re-enable it from the **Actions** tab in one click.

## First-time setup on GitHub

1. Create a free organization named `banglavibedaily`.
2. In it, create a **public** repo named exactly `banglavibedaily.github.io` (no README).
3. Push this project to `main`:
   ```bash
   git remote add origin https://github.com/banglavibedaily/banglavibedaily.github.io.git
   git push -u origin main
   ```
4. **Settings → Pages → Source: GitHub Actions.**
5. The first deploy starts automatically; the site appears at https://banglavibedaily.github.io.
6. Add the site link to the YouTube channel and Facebook page.

Optional later: buy a domain such as `banglavibedaily.com` and add it under **Settings → Pages →
Custom domain**.
